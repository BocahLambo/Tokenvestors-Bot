2. TAB SWITCHING FUNCTIONALITY:
═══════════════════════════════════════════════════════════════════════════
Untuk Filterable Trending, Cryptocurrencies, dan Market Movers:

• Click tab → remove 'active' class dari semua tabs
• Add 'active' class ke tab yang diklik
• Hide semua content containers
• Show content yang sesuai dengan tab (berdasarkan data-tab attribute)
• Smooth fade in/out transition

Example Implementation:
```
tabs.forEach(tab => {
  tab.addEventListener('click', () => {
    // Remove active dari semua
    tabs.forEach(t => t.classList.remove('active'));
    // Add active ke yang diklik
    tab.classList.add('active');
    // Show/hide content
    const targetId = tab.getAttribute('data-tab');
    contentSections.forEach(section => {
      section.style.display = section.id === targetId ? 'block' : 'none';
    });
  });
});
```
